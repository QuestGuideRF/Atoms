# Hydrogen Quantum Orbital Visualizer

Проект визуализирует модели атомов и водородных орбиталей: от простой 2D-симуляции до 3D-визуализации плотности вероятности и raytracer-варианта. Он помогает наглядно посмотреть, как квантовые числа `n`, `l` и `m` влияют на форму орбитали.

## ✨ Возможности

- 2D-симуляция атомов с протонами, электронами и волнами в `src/atom.cpp`.
- 2D-модель волновой орбиты с изменением энергии через клавиатуру в `src/wave_atom_2d.cpp`.
- Realtime 3D-визуализация водородной орбитали с выборкой частиц по квантовым числам в `src/atom_realtime.cpp`.
- Raytracer-визуализация орбитали с расчётом освещения и теней в `src/atom_raytracer.cpp`.
- Python-генератор JSON-точек водородной орбитали в `src/schrodinger.py`.
- Готовые Windows-файлы запуска в папке `bin/`.

## 🛠 Использование

Запуск 2D-симуляции:

```bash
.\bin\atom.exe
```

Запуск raytracer-симуляции:

```bash
.\bin\atom2.exe
```

В 3D-вариантах из исходного кода используются клавиши:

- `W` / `S` — увеличить или уменьшить `n`;
- `E` / `D` — увеличить или уменьшить `l`;
- `R` / `F` — увеличить или уменьшить `m`;
- `T` / `G` — изменить количество частиц `N`.

В 2D-модели `src/wave_atom_2d.cpp` клавиши `W`, `S`, `E`, `D`, `R`, `F` изменяют энергию частицы.

Python-генератор можно запустить так:

```bash
python src\schrodinger.py
```

Скрипт запрашивает `n`, `l`, `m` и количество образцов, после чего создаёт файл вида `orbitals/orbital_n*_l*_m*_complex.json`.
